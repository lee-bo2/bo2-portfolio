01 Mobile UX Design System

포켓CU

편의점 앱 포켓CU의 디자인 시스템 구축과 컴포넌트 고도화. BGF리테일 UXDesignLab에서 설계 일관성과 개발 효율을 동시에 끌어올렸습니다.

클라이언트
BGF리테일
기간
2022.01 — 2022.11
역할
UI/UX Lead Designer
도구
Figma · Zeplin
Problem

무엇이 문제였나

포켓CU는 빠르게 성장하는 편의점 슈퍼앱이었지만, 빠른 기능 추가로 인해 디자인 일관성이 무너지고 있었습니다. 새 화면을 만들 때마다 유사한 컴포넌트가 중복 제작되고, 개발팀은 디자인 파일마다 다른 스펙을 받아 혼란이 가중됐습니다.

핵심 과제 1
컴포넌트 파편화
동일한 버튼이 화면마다 다른 스타일로 구현됨
핵심 과제 2
핸드오프 비효율
디자인-개발 간 스펙 불일치로 수정 반복 발생
핵심 과제 3
온보딩 지연
신규 디자이너가 기존 패턴을 파악하는 데 과도한 시간 소요
Process

어떻게 풀었나

컴포넌트 감사 (Audit)

기존 앱 전체 화면을 스크린샷으로 분석하여 중복·유사 컴포넌트를 분류했습니다. 버튼만 14종, 인풋 필드가 9종으로 산재해 있음을 확인하고 공통화 우선순위를 정했습니다.

공통화 기준 정의

디자인 토큰(색상, 타이포그래피, 스페이싱, 반경)을 먼저 확정하고, 이를 기반으로 Atomic Design 구조로 컴포넌트 계층을 설계했습니다. 개발팀과 함께 토큰 네이밍 규칙을 합의하여 코드와 디자인이 1:1 대응되도록 했습니다.

디자인 라이브러리 구축

Figma에서 Variant 기능을 활용해 상태(default/hover/focus/disabled/error)를 포함한 완전한 컴포넌트 라이브러리를 구축했습니다. 각 컴포넌트에 사용 가이드와 금지 패턴을 문서화하여 팀 전체가 일관되게 사용할 수 있도록 했습니다.

UI 공통화 적용

기존 화면을 라이브러리 컴포넌트로 교체하는 작업을 병행하면서, 신규 기능 개발 시 라이브러리를 먼저 활용하는 워크플로를 정착시켰습니다. Zeplin을 통해 개발 핸드오프 품질도 함께 개선했습니다.

Outcome

무엇이 달라졌나

단일 Figma 라이브러리가 팀 전체의 설계 기준이 되면서, 중복 작업이 줄고 개발팀과의 소통 마찰이 눈에 띄게 감소했습니다.
