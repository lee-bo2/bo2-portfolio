03 E-Commerce UX 통합 전략 AS-IS / TO-BE

롯데ON

분리된 7개 롯데 커머스 채널을 하나의 통합 UX로. AS-IS 현황 분석부터 O2O·개인화·비디오커머스를 포함한 TOBE 설계까지 전 과정을 담당했습니다.

클라이언트
롯데
기간
2019–2021
역할
UI/UX·BX Designer
소속
Regular Bold
Problem

무엇이 문제였나

롯데는 롯데닷컴, 롯데마트, 롯데백화점, 롯데슈퍼 등 7개의 독립적인 커머스 채널을 운영하고 있었습니다. 각 채널은 서로 다른 색상 체계, 쿠폰 정책, 이미지 스타일, 아이콘, 타이포그래피를 사용해 사용자가 하나의 '롯데'를 경험하지 못하는 상황이었습니다.

문제점 1
색상 파편화
채널마다 다른 메인 컬러
문제점 2
쿠폰 UI 비일관
동일 쿠폰이 채널마다 다르게 표시
문제점 3
이미지 스타일 혼재
상품 이미지 촬영 기준 부재
문제점 4
로고 오남용
채널별 로고 사용 기준 미흡
문제점 5
아이콘 파편화
스타일이 다른 아이콘 혼재
문제점 6
타이포그래피 불통일
폰트·크기·행간 기준 없음
Process

어떻게 풀었나

AS-IS 현황 분석

7개 채널의 UI를 전수 분석하여 색상 체계, 쿠폰 디자인, 상품 이미지 가이드, 로고 사용, 아이콘 스타일, 타이포그래피를 항목별로 비교했습니다. 통일이 필요한 요소와 각 채널의 개성을 유지해야 할 요소를 분리하는 것이 첫 번째 과제였습니다.

통합 UX 전략 수립

"Create Sensation" — 감각을 창조한다 — 을 통합 UX의 핵심 슬로건으로 정의했습니다. 단순한 쇼핑 플랫폼을 넘어 개인화된 발견의 기쁨을 제공하는 경험을 설계 방향으로 삼았습니다.

TOBE 설계 — O2O · 개인화 · 비디오커머스

3개 축으로 TOBE를 설계했습니다. O2O: 오프라인 매장과 온라인 채널의 경험 연결. 개인화: 구매 이력과 관심사 기반의 큐레이션 피드. 비디오커머스: 라이브와 숏폼을 통한 감각적 상품 경험. 각 축에 대해 와이어프레임과 프로토타입을 제작하여 롯데 내부와 검증했습니다.

통합 UI 가이드라인 제작

색상 시스템, 타이포그래피, 아이콘, 쿠폰 UI 패턴, 이미지 촬영 기준을 통합 가이드라인으로 문서화했습니다. 각 채널이 독자성을 유지하면서도 '롯데ON'이라는 하나의 브랜드로 인식될 수 있는 균형점을 찾는 것이 핵심이었습니다.

Outcome

무엇이 달라졌나

파편화된 7개 채널이 롯데ON이라는 단일 통합 커머스 플랫폼의 기반을 마련했습니다. 이 프로젝트에서 수립한 통합 UX 전략과 가이드라인은 롯데ON 공식 런칭의 초석이 됐습니다.
