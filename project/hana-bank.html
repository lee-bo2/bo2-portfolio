05 Fintech UX 리뉴얼 가독성

KEB하나은행

구 KEB하나은행 모바일 앱의 전면 리뉴얼. 금융 프로세스 단순화, 가독성 강화, 그리고 통합 브랜드 이미지 전달이라는 세 가지 축으로 UX를 재설계했습니다.

클라이언트
KEB하나은행
기간
2017–2018
역할
UI/UX Designer
소속
넷트루컨설팅
Problem

무엇이 문제였나

KEB하나은행의 모바일 앱은 구 외환은행과 하나은행의 통합 이후 두 은행의 UI가 혼재된 상태였습니다. 통일되지 않은 시각 언어, 낮은 대비의 금융 정보, 여백 없이 밀집된 레이아웃이 사용자 신뢰도와 가독성 모두를 저하시키고 있었습니다.

핵심 과제 1
낮은 가독성
금융 수치(잔액·금리)가 작고 대비가 낮아 읽기 어려움
핵심 과제 2
브랜드 분열
통합 후에도 두 은행의 UI 스타일이 혼재
핵심 과제 3
복잡한 금융 프로세스
금리 조회, 대출 신청 등 주요 플로우가 비효율적으로 구성
Process

어떻게 풀었나

가독성 우선 타이포그래피 체계 수립

금융 앱에서 가장 중요한 정보인 잔액, 이체 금액, 금리를 최우선 계층으로 설정했습니다. 숫자 가독성을 위해 tabular-nums 속성을 적용하고, 금액 단위(원)와 소수점 크기를 구분해 사용자가 금액을 한눈에 파악할 수 있도록 했습니다.

여백과 카드 레이아웃으로 밀집 해소

목록형 UI에서 카드 기반 UI로 전환하여 각 정보 블록 사이에 충분한 여백을 부여했습니다. 구분선과 색상 대신 여백과 카드 배경으로 구역을 나누어 더 깔끔하고 현대적인 인상을 만들었습니다.

통합 브랜드 시각 언어 정의

KEB하나은행의 단일 브랜드 정체성을 앱 전반에 일관되게 적용했습니다. 색상 시스템을 정리하고 Primary 컬러, 상태 컬러(성공/경고/오류), 텍스트 계층을 디자인 토큰으로 정의하여 모든 화면이 하나의 브랜드처럼 느껴지도록 했습니다.

금융 프로세스 단순화

금리 조회, 대출 이자 계산, 환율 변환 등 자주 쓰이는 금융 계산 기능을 탭 구조로 묶어 접근성을 높였습니다. 복잡한 조건 입력 화면도 단계별 프로세스로 재편하여 사용자의 인지 부담을 줄였습니다.

Outcome

무엇이 달라졌나

가독성과 여백 중심의 리뉴얼로 금융 정보를 명확하게 전달하면서도 KEB하나은행의 통합 브랜드 이미지를 일관되게 구현했습니다.
